Back End Development and APIs

Los cinco proyectos de la certificación de freeCodeCamp, servidos por una sola aplicación. Node.js, Express y node:sqlite.

Luis Alberto Carabalí Rivera — portafolio · código

1 · Timestamp Microservice

  • /api/2015-12-25 — fecha con formato
  • /api/1451001600000 — timestamp unix
  • /api/ — sin parámetro, da la hora actual
  • /api/esto-no-es-fecha — inválida

2 · Request Header Parser

  • /api/whoami
  • /api/debug — todo lo que trae la petición

3 · URL Shortener

GET /api/shorturl/1 redirige a la original.

4 · Exercise Tracker

  • /api/users — lista de usuarios
  • POST /api/users/:_id/exercises
  • GET /api/users/:_id/logs?from=&to=&limit=

5 · File Metadata
